Tema 4 · Pilas y Colas en Java

Estructuras de datos lineales

Pilas (LIFO) y Colas (FIFO) explicadas de forma simple y visual

Las pilas y las colas son estructuras lineales muy simples con una regla estricta: no puedes acceder a elementos intermedios; todo entra y sale únicamente por sus extremos.

1 La gran diferencia: LIFO vs FIFO

📚 Pila → LIFO (Last In, First Out)

El último en entrar es el primero en salir.

  • Analogía: una pila de libros. Pones y quitas siempre por arriba (la cima / tope).
  • Mismo extremo: se inserta y se elimina por el mismo sitio.
  • Ejemplo: si metes 1, 2, 3, salen 3, 2, 1.
  • Aplicación clásica: conversión/evaluación de notación postfija.

🎟️ Cola → FIFO (First In, First Out)

El primero en entrar es el primero en salir.

  • Analogía: la fila del cine o del supermercado.
  • Extremos opuestos: se añade por el final y se atiende/elimina por el principio (front).
  • Ejemplo: si metes 1, 2, 3, salen 1, 2, 3.
  • Restricción común: imposible acceder directamente al centro.

2 TAD Pila: operaciones e implementaciones

Operación TAD Nombre en inglés / Java Qué hace exactamente
Inicializar() — Crea una pila vacía (si tenía elementos previos, los suprime). En estática crea el array y pone tope = -1.
Apilar(elem) push(elem) Añade un elemento en la cima. Devuelve true o false (false si una pila estática está llena).
Desapilar() pop() Obtiene y elimina el elemento de la cima (sin índice).
Cima() peek() / top Obtiene el elemento de la cima sin borrarlo.
Vacia() empty() / isEmpty() Devuelve true/false. Conviene comprobarla antes de desapilar.
Limpiar() clear() Vacía toda la pila. En PilaEstatica basta con tope = -1;.

Pila Estática (Array + tope = -1)

  • Usa un array fijo int pila[] y un índice int tope.
  • Vacía: tope = -1 (apunta al último elemento ocupado).
  • Apilar: si tope < pila.length - 1 → primero tope++, luego pila[tope] = v.
  • Cima / Desapilar vacía: lanza Exception("Empty stack!") (no sirve devolver -1 porque podría ser un dato real).

Pila Dinámica (Nodos enlazados)

  • Sin tamaño fijo: nodos [Dato | P] como una lista simple.
  • Un solo puntero tope (inicia en null).
  • Truco clave: se apila y desapila por el extremo izquierdo (tope → Barco → Moto → Coche → null) porque con 1 solo enlace al siguiente es la única forma de actualizar tope = tope.siguiente al desapilar.
¡Ojo en PilaEstatica y ColaEstatica! Si creas new PilaEstatica(6) y olvidas llamar a inicializar(), el array interno sigue siendo null y cualquier operación lanzará NullPointerException. Por eso conviene llamar a inicializar() dentro del propio constructor.

3 TAD Cola: operaciones e implementaciones

Operación TAD Nombre en inglés / Java Qué hace exactamente
Inicializar() — Inicializa la cola. En estática reserva el array y fija ultimoElemento = 0.
Encolar(elem) enqueue / add() / offer() Inserta un nuevo elemento al final de la cola.
Desencolar() dequeue / poll() Devuelve y elimina el primer elemento (FIFO).
Primero() front / peek() Devuelve el primer elemento sin eliminarlo.
Vacia() isEmpty() Indica si la cola está vacía (ultimoElemento <= 0 en estática).

Cola Estática (Array + 1 puntero: ultimoElemento = 0)

  • Solo necesita 1 puntero (ultimoElemento) porque el frente siempre está en cola[0].
  • ultimoElemento apunta a la siguiente casilla libre (por eso empieza en 0).
  • Encolar: si ultimoElemento >= cola.length → excepción; si no, primero escribe cola[ultimoElemento] = n y luego ultimoElemento++.
  • Desencolar (la más compleja): guarda cola[0], desplaza todos los elementos a la izquierda y resta 1 a ultimoElemento.

Cola Dinámica (Nodos + 2 punteros)

  • Usa 2 punteros: primerElemento (por donde sale) y ultimoElemento (por donde entra).
  • Vacía: ambos apuntan a null.
  • 1 solo elemento: ambos apuntan al mismo nodo (89 → null).
  • Desencolar: devuelve dato de primerElemento y avanza primerElemento = primerElemento.siguiente (si queda null, también ultimoElemento = null).

5 Pilas y Colas en Java (java.util)

Aspecto Pilas → java.util.Stack<E> Colas → java.util.Queue<E>
¿Clase o Interfaz? Es una clase (se instancia con new Stack<>()). Es una interfaz (se instancia con new LinkedList<>() u otra colección).
Insertar push(e) add(e) (lanza IllegalStateException si llena) u offer(e) (devuelve false si llena).
Consultar sin borrar peek() peek()
Extraer y borrar pop() poll()
Tamaño size() (no es nativa del TAD, pero Java la ofrece). size() (no es nativa del TAD, pero Java la ofrece).
Ejemplo oficial con Stack<Integer> (LIFO) 
import java.util.Stack;

Stack<Integer> pila = new Stack<Integer>();
for (int i = 1; i <= 5; i++) pila.push(i);
Integer v = pila.peek(); // 5 (size sigue siendo 5)
for (int i = 1; i <= 5; i++) {
    System.out.println(pila.pop()); // Imprime: 5, 4, 3, 2, 1
}
Ejemplo oficial con Queue<Integer> (FIFO) 
import java.util.LinkedList;
import java.util.Queue;

Queue<Integer> cola = new LinkedList<Integer>();
for (int i = 1; i <= 5; i++) cola.add(i);
Integer v = cola.peek(); // 1 (size sigue siendo 5)
for (int i = 1; i <= 5; i++) {
    System.out.println(cola.poll()); // Imprime: 1, 2, 3, 4, 5
}
